# Docker from zero to hero (Arabic): lab files

Companion files for the Udemy course by Ahmed Elfakharany (DevCloudLab), course id 6101143. Rebuilt in 2026-11 from the resources attached to the lectures, plus Phase 0 handouts.

| Path | Lecture / topic |
|---|---|
| `lecture-05-static-website/` | Running a web server with Docker (static site for bind mounts) |
| `lecture-14-ci-cd/` | Creating a CI/CD Docker pipeline (corrected GitHub Actions workflow) |
| `lecture-15-beanstalk/` | Running Docker images on AWS Elastic Beanstalk (Amazon Linux 2023) |
| `lecture-16-compose/` | Deploying multi-containers with Docker Compose |
| `handouts/docker-desktop-windows-macos-ar.md` | Docker Desktop on Windows/macOS (networking and volumes) |
| `handouts/anonymous-volumes-note-ar.md` | Correction note on anonymous volumes |

No secrets are stored here. The compose lab needs your own weather API key in a local `.env` file (not committed); see `.env.example`.
